# 【D 超綱文法】

| 原句 | 文法名稱 | 結構拆解 | 為什麼這樣寫 | 中文翻譯 |
|------|----------|----------|--------------|----------|
| I have always, always enjoyed playing sports. | 現在完成式 | have + 副詞 + 過去分詞 enjoyed | 表示從過去到現在一直有的經驗或狀態 | 我一直一直都很喜歡做運動。 |
| I have gone to soccer, cheerleading, basketball, gymnastics, dance, and baseball. | 現在完成式表示經驗 | have + gone to + 活動 | 強調人生到目前為止參加過的活動 | 我去踢過足球、參加過啦啦隊、打籃球、做體操、跳舞，也打過棒球。 |
| I have always enjoyed playing sports. | enjoy 後接動名詞 | enjoy + V-ing | enjoy 後面若接動作，要用 V-ing 形式 | 我一直都很喜歡做運動。 |
| I don't enjoy watching sports as much as I enjoy playing them. | as much as 比較句 | not + V + as much as + 子句 | 用來比較兩件事喜歡的程度 | 比起看運動比賽，我沒有那麼喜歡；我更喜歡自己去做。 |
| Do you think watching sports is as enjoyable as playing them? | 名詞子句與 as...as 比較 | Do you think + 子句；as + 形容詞 + as | think 後面接一個完整想法，as...as 表示一樣有某種程度 | 你覺得看運動和自己做運動一樣有趣嗎？ |
| I also enjoy going to the gym, but if I don't have time to go to the gym, I always make sure to go for a jog. | if 條件子句 | if + 主詞 + 現在式, 主詞 + 現在式 | 表示在某個條件發生時通常會做的事 | 我也喜歡去健身房，但是如果我沒有時間去健身房，我一定會去慢跑。 |
| It helps me clear my mind. | help + 受詞 + 原形動詞 | help + me + clear | help 後可接受詞，再接原形動詞，表示幫某人做某事 | 它幫助我清空思緒。 |

| It stops me from overthinking. | stop + 受詞 + from + V-ing | stop + me + from + overthinking | 表示阻止某人繼續做某事 | 它讓我停止想太多。 |

| Hobbies like drawing, writing, knitting, gardening, or cooking can be a big help to mental health as well. | like 表示舉例 | 名詞 + like + 例子 | like 在這裡不是「喜歡」，而是「像……這樣的」 | 像畫畫、寫作、編織、園藝或烹飪這些興趣，也能對心理健康有很大的幫助。 |
