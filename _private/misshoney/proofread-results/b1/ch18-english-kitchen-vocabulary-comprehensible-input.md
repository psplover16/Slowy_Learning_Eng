# 【D 超綱文法】

| 原句 | 文法名稱 | 結構拆解 | 為什麼這樣寫 | 中文翻譯 |
|------|----------|----------|--------------|----------|
| I have just come back from the grocery store. | 現在完成式（have/has + p.p.） | 主詞 + have/has + just + 過去分詞 | 用來表示剛完成的動作，並且和現在的狀態有關。 | 我剛從雜貨店回來。 |
| It needs to be furnished with all of the essentials it needs. | need + to be + 過去分詞 | 主詞 + needs + to be + past participle | 公寓是被布置、被配備的對象，所以用 to be furnished 表示被動。 | 它需要配齊所有需要的必需品。 |
| So, I did some grocery shopping for the essentials that my kitchen needs first. | 關係子句 that + 主詞 + 動詞 | 名詞 + that + 主詞 + 動詞 | that my kitchen needs 用來補充說明 essentials 是哪一些必需品。 | 所以，我先去買了一些廚房需要的必需品。 |
| I don't have a car, and even if I did, I don't know how to drive. | even if 條件子句與助動詞替代 | even if + 主詞 + did, 主詞 + 動詞 | did 代替前面的 had a car，用簡短方式表示假設情況。 | 我沒有車，而且就算我有車，我也不知道怎麼開車。 |
| Anything can really be cooked in this pan. | 情態助動詞被動語態 | 情態助動詞 can + be + 過去分詞 | 焦點在東西被煮，而不是誰煮，所以用被動語態。 | 任何東西其實都可以用這個鍋子煮。 |
| It's wide enough and deep enough. | 形容詞 + enough | 形容詞 + enough | enough 修飾形容詞時放在形容詞後面，表示程度足夠。 | 它夠寬，也夠深。 |
| As I was walking home, I realized I forgot to buy a dustpan. | 過去進行式時間子句 | As/While + 主詞 + was/were + V-ing, 主詞 + 過去式動詞 | 用過去進行式描述當時正在發生的背景動作，再接另一個發生的動作。 | 我走回家的時候，才發現我忘了買畚斗。 |
| Let me know in the comments what else you can peel! | 間接問句語序 | 疑問詞 + 主詞 + 助動詞 + 原形動詞 | what else you can peel 是嵌入在句子裡的問題，所以用 you can，不用 can you。 | 請在留言區告訴我，你還可以削什麼！ |
| This is my first time living alone. | This is my first time + V-ing | This is + 所有格 + first time + V-ing | 用來表示某人第一次做某件事或有某種經驗。 | 這是我第一次獨居。 |
| I'm going to be buying lots of essentials that I never had to buy before. | be going to be + V-ing（未來進行） | 主詞 + be going to + be + V-ing | 表示未來一段時間會持續或反覆進行的動作。 | 我會買很多以前從來不需要自己買的必需品。 |
| Turn on the bell notifications so you can be notified every time I post a new video. | so + can + 被動語態 | so + 主詞 + can + be + 過去分詞 | so 引出目的或結果；can be notified 表示你能被通知。 | 開啟鈴鐺通知，這樣每次我發布新影片時，你都能收到通知。 |
