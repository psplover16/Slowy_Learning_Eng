# _private/misshoney

Raw import outputs and content drafts for the MissHoney playlist module.
These files are **not committed to git** (see `.gitignore`) and are never loaded by the app bundle.

## Folders

| Path | Contents |
|------|----------|
| `inventory/<level>.json` | Playlist metadata清冊：videoId, title, slug, displayOrder, originalIndex, status |
| `transcripts/<level>/<slug>.json` | Normalized English caption cues and merged transcript text |
| `skipped/<level>.json` | Videos that could not be imported, with reason |
| `import-summary.json` | Per-level counts: inventory, transcripts, skipped, missing transcripts |
| `content-scaffolds/<level>/<slug>.json` | Authoring scaffolds generated by `scaffold-content` — source material only, no TC translation |
| `generated-content/<level>/<slug>.json` | Complete `PlaylistVideoData` authored by the apply agent — ready for validation and promotion |

## Commands

```bash
# Fetch all playlists and captions from YouTube (requires yt-dlp)
npm run misshoney:import

# Verify existing raw outputs without calling YouTube
npm run misshoney:import -- --check-existing

# Generate authoring scaffolds from transcripts (no TC translation produced)
npm run misshoney:scaffold-content -- --level a1
npm run misshoney:scaffold-content -- --all

# Validate generated/promoted content completeness
npm run misshoney:validate-content -- --level a1
npm run misshoney:validate-content -- --all

# Promote validated content into app data
npm run misshoney:promote-content -- --level a1
npm run misshoney:promote-content -- --all
```

## Re-run behavior

- `misshoney:import` is safe to re-run. It skips videos whose transcript file already exists.
- It **never** writes to `src/modules/playlists/data/videos/**`.
- If a transcript is overwritten, any previously promoted app content at the matching path is not affected.

## Skipped reasons

| Reason | Meaning |
|--------|---------|
| `no-english-captions` | No public English subtitles or auto-captions available |
| `member-only` | Video is restricted to channel members |
| `private` | Video is set to private |
| `unavailable` | Video is deleted, unlisted with expiry, or otherwise unavailable |
| `geo-restricted` | Video is blocked in the user's region |

Videos with any of the above reasons appear only in `skipped/<level>.json`.
They are not assigned a slug or displayOrder, and no content is generated for them.

## Manual subtitle fetching is out of scope

This workflow does not support manually pasting subtitles.
If a video has no public English captions, it is recorded as `no-english-captions` and skipped.
The apply agent does not author content for skipped videos.
